# limits-band

Над полем ввода — компактная полоска: персонаж Токи, заполненность контекста и лимиты подписки (5 часов, неделя) с временем до сброса. Кнопка «Панель» (или /limits) открывает карточку лимитов: крупный процент, шкалы, стоимость сессии, 7 тем (Классика, Хэллоуин, Космос, Океан, Полночь, Лес, OLED) и 8 скинов персонажа (Классика, Паучок, Тыква, Призрак, Корона, Шапка, Наушники, Колпак). Настроение Токи зависит от расхода лимитов. Когда ответ готов, звучит глубокий тёплый перезвон. Выбор темы, скина и звука сохраняется между сессиями. /limits hide прячет полоску.

## Установка

В строке ввода сессии Claude Code:

```
/plugin install limits-band --marketplace Arche7/claude-limits
```

Затем ответьте `y`, чтобы добавить маркетплейс, и выберите, где установить.

Из терминала:

```
claude plugin install limits-band --marketplace Arche7/claude-limits
```
